## Description（描述，复制）

```
ReceiptBox turns "can I actually pay this invoice?" into a self-hosted MCP server
(MCP spec 2025-11-25, Streamable HTTP) on the Amazon Alexa+ track. Any MCP host —
Alexa+, Claude Desktop, or a self-built agent — can call it before money moves.

It catches the losses that actually hurt small businesses and freelancers:
  • price/tax mismatches and wrong tax rates
  • duplicate payments (double-pay is the most common real cash leak)
  • every finding comes with cited evidence — not a black-box verdict

Plus a simulated Alexa+ web console so anyone can experience the full loop without
configuring MCP. This 28-second demo runs the real auditor on a real invoice:
a duplicate and a tax mismatch are flagged with evidence, a clean invoice passes.
```
